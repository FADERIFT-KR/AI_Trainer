[2026-09-19] z축 2D->3D lifting 연구·구현·검증
======================================================================

질문/요청
- 웹캠 2D 관절에서 3D lifting 시 z축 추론 정확도를 높이는 연구 조사 및 적용.
- 검증이 dataset 정면 2D 키포인트로 추론한 3D와 dataset 3D 키포인트를 비교한 것인지 확인.

답변/작업 요약
- VideoPose3D, MotionBERT, Ray3D를 조사함.
- 현재 보유 데이터·카메라 조건에서는 대형 사전학습 가중치가 필요한 MotionBERT, 정확한 내·외부 카메라 파라미터와 재학습이 필요한 Ray3D보다 VideoPose3D 계열의 시간축 확장이 현실적인 후보로 판단됨.
- 27프레임 대칭 temporal convolution, z축 가중 손실, bone-length 정규화를 가진 V2를 구현하고 actor 분리 검증을 수행함.
- 검증 입력: AI Hub 정면 camera 1 2D 키포인트.
- 검증 정답: 같은 시퀀스·중심 프레임의 dataset 3D 키포인트.
- 기존 9프레임 lifting 모델 검증 결과:
  MPJPE 50.51 mm, x MAE 27.25 mm, y MAE 22.81 mm, z MAE 25.50 mm.
- 신규 27프레임 V2 검증 결과:
  MPJPE 61.58 mm, x MAE 32.87 mm, y MAE 21.48 mm, z MAE 36.46 mm.
- V2의 z축 오차가 10.96 mm 악화되어 운영 경로에 채택하지 않음. 자동 선택 파일은 기존 9프레임 모델을 선택하도록 기록함.
- 중요한 구분: 이 lifting 검증은 오프라인 dataset 실험이다. 실제 사용자 판정은 MediaPipe world 3D를 사용하며, AI Hub 정면 2D lifting 모델로 대체하지 않음.
